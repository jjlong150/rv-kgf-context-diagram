# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - Initial Release

First release as a standalone repository. This toolkit grew out of the diagram-only context diagram example in the [Relationship Visualizer](https://github.com/jjlong150/ExcelToGraphviz) samples. It now adds:

- **RV-KGF knowledge graph export:** every style and every row carries structured properties.
- **An architecture design review prompt** that turns the knowledge graph into an AI-written assessment report.
- **Instance-level attributes** covering data classification, PII, authentication, failure handling, lifecycle and hosting.
- **A governance color scheme** tied to each connection pattern's approval status.
- **A user guide, a generated style catalogue, and text copies** of the styles and SQL for reviewable changes.
